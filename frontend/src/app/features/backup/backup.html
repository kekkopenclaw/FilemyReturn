Keeping backups safe

  • On the free hosting tier the database and the uploaded files live on disk that is wiped on every redeploy — a backup only helps if it is downloaded off this server. Download one before every deploy, at least.
  • A backup holds every workspace's documents. Treat the ZIP like a password: encrypted storage, never emailed or shared. Every download is written to the audit log.
  • Restoring is a manual procedure — stop the app, replace the database file and the storage folder with the backup's contents, restart. The full steps are in docs/BACKUP.md.
